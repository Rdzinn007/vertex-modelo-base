# VERTEX — Base de Projetos

Repositório de referência para organizar os projetos de desenvolvimento da VERTEX.

## Objetivos
- Desenvolver sites institucionais e landing pages.
- Criar sistemas SaaS e aplicações web.
- Organizar projetos e documentar padrões.
- Manter o histórico de alterações.

## Ferramentas
- Lovable
- Supabase
- GitHub
- Codex

## Segurança
- Nunca publicar senhas, tokens ou chaves secretas.
- Proteger os dados dos clientes.
- Configurar permissões e RLS no Supabase.
- Testar as alterações antes de publicar.

## Fluxo de desenvolvimento
1. Planejar o projeto.
2. Desenvolver na Lovable.
3. Configurar o banco e a autenticação no Supabase.
4. Sincronizar o código com o GitHub.
5. Revisar, testar e publicar.
